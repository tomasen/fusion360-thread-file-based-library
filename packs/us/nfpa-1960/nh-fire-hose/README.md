# NH/NST national fire-hose thread pack

This pack adds the complete 11-size **NH** series in NFPA 1960:2024, from
3/4-8 through 8-4, with external and internal modeled profiles. `NST` is the
common trade name for the same National Hose thread family.

The 3/4-8 and 1-8 designations intentionally have identical thread geometry;
their nominal waterways differ. Each Fusion profile uses the midpoint of the
published tolerance where a range is given.

Fire-hose threads can differ by jurisdiction. Confirm the local fire
department/AHJ designation and verify with calibrated gauges before making a
life-safety, pressure-rated, or interoperability-critical part.
