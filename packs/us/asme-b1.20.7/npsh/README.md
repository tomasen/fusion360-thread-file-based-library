# NPSH straight hose thread pack

This pack adds the complete 10-size **NPSH** series from 1/2-14 through 4-8,
with external and internal modeled profiles. NPSH is a straight hose-coupling
thread used for steam, air, water, and general hose service. The joint normally
seals with a gasket, not on the thread flanks.

Each Fusion profile uses the midpoint of the published tolerance where the
standard provides a range and the specified limiting value where it provides
only one diameter limit.

## References

- [ASME B1.20.7-1991 (R2024)](https://www.asme.org/codes-standards/find-codes-standards/b1-20-7-hose-coupling-screw-threads)
- [FED-STD-H28/10 document record](https://quicksearch.dla.mil/qsDocDetails.aspx?ident_number=53611)

NPSH is straight and is not NPT. Verify the exact mating connection and seal
before production or pressure service.
